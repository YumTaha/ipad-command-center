# Setup

For the deployed private agenda, scan the separately provided private setup QR on the iPad and open its dashboard link. It contains the display bearer key: do not publish it, commit it, or share its image/link. The page accepts only the exact deployed agenda endpoint and a 64-character hexadecimal display key, removes the setup fragment before requesting data, then saves settings in this browser. Invalid setup fragments are cleared and ignored. Add the cleaned page to the Home Screen afterward. Revoke the display key if the QR or device is exposed. This configures this browser only; another browser or Home Screen session may need its own setup.

1. Publish these files at the root of a GitHub Pages repository. In GitHub Settings → Pages, select the branch and root folder. Wait for the HTTPS Pages URL. To update, commit changed files to the same publishing branch, wait for deployment, and reopen the page on the iPad.
2. On the iPad, open the HTTPS URL in Safari. Verify weather and clock before adding it to the Home Screen. Configure Auto-Lock, brightness and Guided Access in iPad settings. The web page cannot control battery charging or guarantee Safari remains awake.
3. This installation uses **Private agenda endpoint** for automatic UC Outlook updates, configured by the private setup QR. The protected Cloudflare proxy stores the Outlook feed and key as server-side secrets. For another installation, deploy a protected proxy separately and enter only its HTTPS URL and display bearer token here. **Local ICS file** remains an alternative: export a file and import it in Settings as described below. Publishing an Outlook ICS feed creates a secret bearer URL even if the proxy protects its output. Do not commit calendar URLs or tokens to GitHub. A restricted display-only calendar limits exposure.
4. The endpoint must allow this dashboard origin through CORS and support an Authorization preflight when a token is used. It must return JSON as below. Timed dates need explicit `Z` or numeric offsets. All-day start/end are `YYYY-MM-DD`; end is exclusive. The dashboard displays the current Sunday–Saturday week in Eastern time, from midnight to midnight, with all-day items in a separate row. The deployed feed supplies upcoming events and active events; past appointments are not reconstructed. Events crossing midnight are split across day columns and overlapping blocks share column width. Tap a block for its full title and time. Event text is displayed as text, never HTML.

```json
{"events":[{"title":"Display event","start":"2026-10-12T14:00:00Z","end":"2026-10-12T15:00:00Z","allDay":false},{"title":"All-day event","start":"2026-10-13","end":"2026-10-14","allDay":true}]}
```

5. For a local option, export or download an ICS file from Outlook, transfer it to the iPad's Files app, then select Local ICS in Settings. The file is read on this device; nothing is uploaded. Imported events display only **Busy**, and the original file, descriptions, attendees and locations are not stored by this page. Save settings commits the staged import; closing Settings discards it. The snapshot includes the next 30 days and the dashboard displays the next seven. Import again for changes or dates beyond that window. The pinned local ICAL.js 1.5.0 parser supports embedded Outlook/Windows `VTIMEZONE`, daily/weekly/monthly/yearly recurrence, exclusions, moved exceptions and cancellations. All-day dates remain civil dates. It rejects floating or undefined zones, high-frequency recurrence, EXRULE, RDATE periods and THISANDFUTURE range exceptions visibly. Large/slow calendars are rejected rather than partially imported. A real UC export still needs verification on the iPad.

   Google Calendar is an alternative: it accepts only its HTTPS `/calendar/embed` URL, and forces agenda mode/Eastern display. Private signed-in embeds can fail in old Safari. Sample events appear only if you explicitly choose preview mode.
6. Weather and private agenda refresh every 15 minutes, retry failed requests after a minute, and refresh when the display becomes visible or reconnects. Weather retains a last-known local cache, marked stale after 30 minutes. Private agenda remains in memory and is marked stale after 30 minutes; an iframe's availability cannot be verified by this page. There is no scheduled forced reload.

Settings and bearer tokens in localStorage are accessible to anyone using this iPad and any script served from the same origin. Clear calendar removes this page's saved calendar configuration and imported events. GitHub Pages repositories under the same username hostname share an origin; different repository paths do not isolate storage. Use a distinct hostname if credential isolation is needed, avoid signing into sensitive accounts on iOS 12, and revoke the display token if the device is lost. Local snapshots show their age and request another import before the remaining coverage falls below seven days; once expired, the empty state explicitly asks for another import.

Test portrait (768 × 1024) and landscape (1024 × 768), an offline/reconnect cycle, night dimming, and at least a day of uptime on the actual iPad. Charging strategy and campus Wi-Fi setup require device and network checks separately.



Calendar view is saved per browser: Settings → Calendar view → 1 day, 3 days, or Week → Save settings. The default is 3 days. Shorter views start today in Eastern time and roll forward at midnight; Week starts Sunday. All views keep the full 24-hour range. Wider short-view event blocks wrap titles and reserve a line for the start time; crowded or very short events may still need a tap for full details.
